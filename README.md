# SpendPing

A React Native mobile application for managing transactions and tracking expenses.

## 🛠️ Technologies Used

- **Framework:** React Native with [Expo](https://expo.dev/)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (via [NativeWind](https://www.nativewind.dev/))
- **State Management:** [Zustand](https://github.com/pmndrs/zustand)
- **Local Database:** Expo SQLite
- **Navigation:** React Navigation
- **Storage:** AsyncStorage
- **Icons:** Phosphor Icons

## 🚀 How to Develop

1. **Branching Strategy:** 
   - All active development should be done on the `develop` branch.
   - To start working, checkout to the develop branch:
     ```bash
     git checkout develop
     ```

2. **Installation:**
   Ensure you have Node.js installed, then run:
   ```bash
   npm install
   ```

3. **Running the App Locally:**
   Start the Expo development server:
   ```bash
   npm start
   ```
   - Press `a` to run on Android.
   - Press `i` to run on iOS.
   - Press `w` to run on the Web.
